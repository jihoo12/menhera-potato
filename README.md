# menhera-potato

A small Rust project (library + CLI/binary).

## Overview

- Library code: `src/`
- Binary entrypoint: `src/main.rs`
- Tests: `tests/`

## Build

```bash
cargo build --release
```

## Run

```bash
cargo run --release
```

## Test

```bash
cargo test
```
